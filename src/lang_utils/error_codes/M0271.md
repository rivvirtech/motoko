# M0271

This error means that the program uses `Nat128` or `Nat256` while compiling for
classical (legacy) persistence.

The wide fixed-width naturals are held as fixed-size limb values in the enhanced
orthogonal persistence heap layout and are compiled only by that backend. They are not
available with `--legacy-persistence`.

Erroneous code example:

```motoko
// compiled with --legacy-persistence
let x : Nat256 = 1;
```

To fix, compile with enhanced orthogonal persistence (the default), or use `Nat` where
classical persistence is required.
